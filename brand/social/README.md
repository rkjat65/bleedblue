### Profile grid banner

Three 1080 x 1440 posts (3:4, the grid's own shape) that join into one banner. Post them in this order so they read left to right:

1. `instagram-grid-3.png` (formats and link)
2. `instagram-grid-2.png` (name)
3. `instagram-grid-1.png` (mark)

Caption for each: `Crickrida: cricket in numbers. Link in bio.`

### Highlight covers

Add a story with each image, then save it as a highlight cover. Suggested order: IPL, T20 WC, Tests, ODIs, T20Is, Records.

`instagram-highlight-ipl.png`, `instagram-highlight-t20-wc.png`, `instagram-highlight-tests.png`, `instagram-highlight-odis.png`, `instagram-highlight-t20is.png`, `instagram-highlight-records.png`
